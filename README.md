# NTHU Study Notes

A small, extendable EECS study website by Kenshin Hara (NTHU IBP, major in EECS).

## Project idea
A beginner-friendly notebook for courses such as Computer Architecture, Logic Design, Probability and Machine Learning. Notes include a concept, example and self-check question.

## What makes it reusable?
`AGENTS.md` documents a consistent note schema, styling, routing, file structure, quality checklist and AI workflow. Adding another topic only requires one new note object; the home card, searchable listing and note page are generated automatically.

## Features
- Subject filters and instant search
- Dedicated shareable pages via URL hashes
- Worked examples and revealable quiz answers
- Responsive layout; no framework or build dependencies
- Three sample notes

## Run
Open `index.html` locally in a browser, or publish it with GitHub Pages (Settings → Pages → Deploy from a branch → main → /root → Save).

## AI extension instruction
"Read AGENTS.md, then add one Beginner note about pipelining. Do not change the existing layout. Check the new page, filters and question-answer interaction."

## Technologies
HTML, CSS, vanilla JavaScript, GitHub Pages.

## Disclaimer
